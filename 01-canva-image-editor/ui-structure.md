# Canva 图片编辑器 · UI 结构

> 维度一：面板布局、工具栏、操作流、页面跳转。基于 `[DOC]`（官方无障碍说明 + 教程）与 `[INF]`。

## 1. 四区布局（[DOC]）

```
┌──────────────────────────────────────────────────────────────┐
│ 顶部主导航: 文件 | 撤销/重做 | 分享 | 下载 | 缩放/网格/全屏      │
├─────────────┬────────────────────────────────┬───────────────┤
│ 左侧侧面板   │           中央画布 Canvas        │ 右侧属性面板   │
│ Templates    │     (设计工作区, 多页可切换)     │ (选中元素后)  │
│ Elements     │                                │ 颜色/字体/    │
│ Text         │                                │ 透明度/位置/  │
│ Uploads      │                                │ 动效/图层    │
│ Tools        │                                │               │
│ Apps         │                                │               │
│ Add page     │                                │               │
│ Notes/Timer  │                                │               │
├─────────────┴────────────────────────────────┴───────────────┤
│ 底部: 页面缩略图(Pages) | 缩放 | 网格视图 | 全屏 | 备注         │
└──────────────────────────────────────────────────────────────┘
```

- **左侧侧面板（Side Panel）**标签（[DOC] Canva 无障碍说明原文）：`模板 Templates` · `素材/元素 Elements` · `文字 Text` · `已上传 Uploads` · `工具 Tools` · `应用 Apps` · `添加页面 Add page` · `备注 Notes` · `计时器 Timer`。
- **顶部主导航**（[DOC]）：`文件 File`（文档级，如命名/版本）、`撤销/重做`、`分享 Share`、`下载 Download`，以及 `缩放`、`显示页面缩略图`、`网格视图`、`全屏`。
- **右侧属性面板**：仅在**选中元素后出现**（[DOC] 教程一致描述），提供颜色、字体、透明度、位置、动效、图层顺序等。
- **底部页面条（Pages）**：多页设计（如演示文稿、多页文档）的缩略图导航（[DOC] `Pages`）。

## 2. 左侧面板各标签职责（[DOC]/[INF]）

| 标签 | 作用 |
| --- | --- |
| 模板 Templates | 搜索/套用模板，一键带入布局与元素 |
| 元素 Elements | 图形、图标、照片、插画、图表、线条、网格等素材库 |
| 文字 Text | 添加标题/正文/艺术字，字体与样式 |
| 已上传 Uploads | 上传并管理本地图片/视频/音频，拖入画布 |
| 工具 Tools | 内置工具（如背景去除、AI 图层等） |
| 应用 Apps | 第三方/扩展能力接入 |
| 添加页面 Add page | 新建页面（多页文档） |
| 备注 Notes | 协作者评论/备注 |
| 计时器 Timer | 演示计时辅助 |

## 3. 典型操作流（[DOC]）

1. 从**模板**或空白画布开始 → 自动保存。
2. 在左侧面板选 `元素/文字/已上传` → **拖拽**到画布（或点击添加）。
3. 点击画布元素 → 出现**选中框 + 右上上下文工具条**（复制/删除/图层/锁定/链接/评论等）。
4. 右侧属性面板微调（颜色/字体/透明度/位置/动效）。
5. 多页：底部 `Pages` 切换/增删页面。
6. 顶部 `分享`（生成协作链接/权限）或 `下载`（PNG/JPG/PDF 等）。

## 4. 页面跳转与多页（[DOC]）

- 单设计可含多页（演示、文档、社媒系列），通过底部 `Pages` 缩略图切换。
- 页面切换不离开编辑器，属同一设计文档内的「页面栈」导航（[INF]）。

## 5. 与 Photopea 布局对比（预告）

| | Canva 图片编辑器 | Photopea |
| --- | --- | --- |
| 布局范式 | 素材库 + 画布 + 上下文属性面板 | 菜单栏 + 工具栏 + 图层面板 + 选项栏 + 画布 |
| 对象模型 | 元素即对象（DOM/SVG） | 图层栈（画布像素/矢量） |
| 入口复杂度 | 拖拽式、低门槛 | 专业式、高门槛 |
| 协作 | 强（云原生） | 弱（本地） |

详见 `04-comparison.md`。
