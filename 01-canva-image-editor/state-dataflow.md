# Canva 图片编辑器 · 状态与数据流

> 维度二：选中态、撤销栈、文档模型、数据流。Canva 内部为黑盒，以下以 `[DOC]` 公开特性与 `[INF]` 推断为主，未做实跑抓取。

## 1. 文档模型（[INF]）

Canva 的一个「设计（Design）」可建模为：
- **页面列表（Pages）**：每页是一组元素的容器（多页设计如演示/文档）。
- **元素列表（Elements）**：每页下挂元素（文本、图片、形状、图标、图表、视频、上传素材等），每个元素是一棵属性树（位置/尺寸/旋转/样式/层级/动效）。
- **设计级元数据**：标题、尺寸（画布比例）、品牌套件引用、协作者、版本。

> 与 Photopea 的「图层栈 = 像素/矢量合成」不同，Canva 是**结构化对象树**，元素彼此独立、可被单独选中/编辑/编组/锁定（[INF]）。

## 2. 选中态（[DOC]/[INF]）

- 单击画布元素 → 进入「选中态」→ 显示选中框 + 上下文工具条 + 右侧属性面板（[DOC]）。
- 支持多选、编组（`Ctrl+G`，[DOC]）、锁定、图层顺序调整。
- 选中态驱动右侧属性面板内容（属性面板是**上下文相关**的，而非固定）。

## 3. 撤销 / 重做（[DOC]）

- 顶部提供 `撤销/重做`；快捷键 `Ctrl+Z` / `Ctrl+Shift+Z`（[DOC]）。
- 推断为**命令栈**（每个用户操作记录为可撤销命令），并可能与云端版本历史联动（[INF]）。

## 4. 自动保存与同步（[DOC]）

- Canva 官网明确「更改会自动保存」「跨设备同步」（[DOC]）。
- 因此数据流中**持久化是默认且持续的**：每次变更（防抖后）写云端，协作者实时可见（[INF]）。

## 5. 数据流（[INF]）

```
用户操作(拖拽/点击/属性调整)
   │
   ▼
命令: 修改元素/页面属性 (选中态 + 上下文面板驱动)
   │
   ▼
本地模型更新 → 压入撤销命令栈
   │
   ▼
视图刷新: 重渲染受影响元素(DOM/SVG diff, [INF])
   │
   ▼
持久化: 防抖后写云端(自动保存) → 通知协作者(实时同步)
   │
   ▼
导出: 服务器端按元素树渲染为目标格式(PNG/JPG/PDF…, [INF])
```

### 关键差异（对比 Photopea）
- **持久化**：Canva 实时云端；Photopea 本地优先、导出文件。
- **协作**：Canva 云原生多人实时；Photopea 偏单用户本地。
- **渲染位置**：Canva 元素在 DOM/SVG（客户端交互 + 服务器端导出）；Photopea 图像在 `<canvas>`（客户端合成）。
