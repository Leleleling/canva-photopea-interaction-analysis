# Canva 图片编辑器 · 事件机制

> 维度三：指针/键盘/手势、命中测试、拖拽/缩放/对齐。基于 `[DOC]` 与 `[INF]`（元素即 DOM/SVG 对象，故命中测试交由浏览器）。

## 1. 事件范式（[INF]）

由于 Canva 的元素是**真实 DOM/SVG 节点**（[INF]），其画布交互与 Photopea 的「自研命中测试」根本不同：
- **命中测试交给浏览器**：点击元素即触发该 DOM 节点的事件，无需自绘命中。
- 框架（React 等，[INF]）绑定指针/键盘事件到元素与画布容器。
- 选中、拖拽、缩放由元素上的事件处理器 + 全局指针事件协同完成。

## 2. 拖拽（[DOC]）

- 从左侧面板**拖拽素材到画布**即创建元素（[DOC] 多家教程描述）。
- 画布内拖拽移动元素；松手吸附到对齐参考线（见下）。

## 3. 选中与控制柄（[DOC]/[INF]）

- 单击元素 → 选中 → 四角/边出现**缩放柄**、顶部/侧出现**旋转柄**，拖动改尺寸/旋转。
- 选中后画布上方出现**上下文浮动工具条**（复制/删除/图层/锁定/评论/动画等，[DOC]）。
- 右侧属性面板随选中元素类型变化（文本→字体面板；图片→裁剪/滤镜面板；形状→填充面板）。

## 4. 对齐与吸附（[INF]）

- 移动元素时显示**智能参考线/对齐线**（与其它元素或画布中心对齐），松手吸附（[INF]，Canva 常见行为）。
- 可能与「吸附网格」「间距均分」辅助共存。

## 5. 缩放与平移（[DOC]）

- `Ctrl+滚轮` 缩放画布（[DOC]）。
- 抓手/空格拖拽平移（[INF] 通用编辑器行为）。
- 顶部 `缩放` 控件与 `网格视图`/`全屏`（[DOC]）。

## 6. 键盘快捷键（[DOC]）

- `Ctrl+D` 复制元素、`Ctrl+G` 编组、`Ctrl+Z` 撤销、`Ctrl+Shift+Z` 重做、`Ctrl+滚轮` 缩放（[DOC]）。
- 方向键微移选中元素、`Ctrl+方向键` 大幅移动（[DOC] Canva 无障碍说明）。

## 7. 手势（[DOC]/[INF]）

- 移动端：底部工具条替代左侧面板；双指缩放替代滚轮；长按唤起更多选项（[DOC] 教程描述）。

## 8. 与 Photopea 对比（预告）

| | Canva | Photopea |
| --- | --- | --- |
| 命中测试 | 浏览器 DOM 命中 | 自研画布命中测试 |
| 对象选择 | 点 DOM 节点 | 点画布→图层栈反查 |
| 控制柄 | 元素四周 DOM 柄 | 包围框 + 变换控件 |
| 上手成本 | 低（所见即所得） | 高（专业工具语义） |

详见 `04-comparison.md`。
