# Canva 图片编辑器 · 画布渲染模型

> 维度四：图层、坐标系、渲染与导出序列化。基于 `[DOC]` 与 `[INF]`（Canva 元素即 DOM/SVG，与 Photopea 单一 canvas 截然不同）。

## 1. 渲染表面：DOM / SVG（[INF]）

- Canva 画布中的**每个元素都是独立的 DOM/SVG 节点**（文本=SVG/HTML 文本，形状=SVG，图片=`<img>`/canvas 缩略图，[INF]），而非画在一张位图 canvas 上。
- 优点：元素可被浏览器原生命中/选中/无障碍访问，属性面板直接改样式；缺点：超多元素时 DOM 节点膨胀，需虚拟化/裁剪优化（[INF]）。

## 2. 图层与层级（[INF]）

- 「图层」= 元素在页面内的**堆叠顺序**（z-order），可在右侧/上下文面板调整前后顺序、编组、锁定。
- 与 Photopea 的「像素图层 + 混合模式 + 通道 + 蒙版」相比，Canva 图层是**对象级顺序**，非破坏式混合能力较弱（[INF]）。

## 3. 坐标系（[INF]）

- 元素位置以**相对画布/页面的布局坐标**表示（百分比或像素），配合画布缩放做视图变换；对齐参考线基于这些坐标计算。
- 不同于 Photopea 的「文档坐标 + 视图矩阵」，Canva 更偏向**响应式布局坐标**（适配多尺寸导出）。

## 4. 导出与序列化（[DOC]/[INF]）

- 下载支持 PNG/JPG/PDF 等（[DOC] 顶部 `下载`）；PDF 编辑器还可导出 SVG/PPT（见 `02-canva-pdf-editor`）。
- 推断：导出由**服务器端按元素树重新渲染**为目标格式（保证跨设备一致、与编辑视图解耦），而非客户端位图截取（[INF]）。这与 Photopea 的「客户端 canvas 直接导出」形成差异。

## 5. 实时协作渲染（[INF]）

- 因元素为结构化对象且状态在云端，多人光标/选中/编辑可实时叠加显示（[INF]，Canva 协作特性）。

## 6. 对比 Photopea（预告）

| 维度 | Canva 图片编辑器 | Photopea |
| --- | --- | --- |
| 图像表面 | DOM/SVG 元素节点 | 单一 `<canvas>` 像素合成 |
| 图层语义 | 对象 z-order | 像素图层 + 混合模式/通道/蒙版 |
| 导出 | 服务端按元素树渲染 | 客户端 canvas 导出 |
| 协作渲染 | 实时多人叠加 | 单用户本地 |

详见 `04-comparison.md`。
