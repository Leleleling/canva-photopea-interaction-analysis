# Canva PDF 编辑器 · 画布渲染模型

> 维度四：图层、坐标系、渲染与导出序列化。基于 `[DOC]` 与 `[INF]`。

## 1. 渲染表面：DOM/SVG + PDF 页底图（[INF]）

- 与图片编辑器一致，编辑态元素为 **DOM/SVG 节点**（[INF]）。
- 每个 PDF 页在画布上呈现为**一页（含被拆出的元素 + 批注叠加）**；原 PDF 页面可能以位图/矢量底图承载，其上叠加可编辑元素（[INF]）。

## 2. 图层与层级（[INF]）

- 与图片编辑器相同：元素是对象级 z-order，可编组/锁定/调序。
- 额外存在**批注层**：线条/形状/签名/评论叠加于原内容之上，与原内容解耦（[INF]，保证批注可独立增删而不破坏原文）。

## 3. 坐标系（[INF]）

- 元素以相对页面的布局坐标表示，适配页面尺寸与导出；多页共用同一坐标系范式，按页面索引隔离。

## 4. 导出与序列化（[DOC]/[INF]）

- 可下载为 **PDF / JPG / PNG**，并可导出 **SVG / PPT**（[DOC]）。
- 推断导出流程：按**页面顺序**将每页的元素/批注重新合成，生成目标格式（PDF 保留页面；JPG/PNG 逐页或整页栅格化；SVG/PPT 转结构化格式），由**服务端渲染**保证一致性（[INF]，同图片编辑器）。
- 上限：≤100MB、≤300 页（[DOC]），导出需遵守该约束。

## 5. 与 Photopea / 图片编辑器对比（预告）

| 维度 | Canva PDF 编辑器 | Canva 图片编辑器 | Photopea |
| --- | --- | --- | --- |
| 页面模型 | 多页 PDF（一等公民） | 多页设计 | 单画布无页面 |
| 批注层 | 有（叠加，不破坏原文） | 弱（备注） | 无 |
| 导入拆解 | 服务端版式/OCR → 元素 | 无 | 弱（栅格/矢量页） |
| 导出 | PDF/JPG/PNG/SVG/PPT | PNG/JPG/PDF | PSD/位图/PDF |
| 渲染 | 客户端编辑 + 服务端导出 | 同左 | 客户端 canvas 导出 |

详见 `04-comparison.md`。
