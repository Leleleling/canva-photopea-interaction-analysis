# Canva PDF 编辑器 · 状态与数据流

> 维度二：选中态、撤销栈、文档模型、数据流。基于 `[DOC]` 与 `[INF]`。

## 1. 文档模型（[DOC]/[INF]）

导入后的 PDF 在 Canva 内部被表示为：
- **页面列表（Pages）**：每页对应一个 PDF 页，含「底图/原内容（被拆成的元素）+ 叠加批注/编辑」。
- **页面元素**：识别出的文本、图片、形状 → 转为 Canva 元素（可被单独选中/编辑）。
- **批注层**：线条/形状/签名/评论作为叠加元素或评论数据，与原内容分离（[INF]，便于不破坏原文地批注）。
- **设计级元数据**：原始 PDF 信息、页面顺序、协作者、版本。

## 2. 导入拆解管线（[DOC]）

- 「将 PDF 文件分解成可以编辑的元素」「自动识别并将内容变成可编辑的元素」（[DOC]）。
- 推断：上传后服务端执行**版式分析 / OCR / 文本-图像分离**，产出一个 Canva 设计文档（[INF]）。该步骤是 PDF 编辑器的核心差异能力，也是 Photopea 不具备的（Photopea 打开 PDF 多为栅格/矢量页，缺结构化拆解）。

## 3. 选中态与撤销（[DOC]/[INF]）

- 与图片编辑器一致：选中元素出属性面板与上下文工具条；`Ctrl+Z`/`Ctrl+Shift+Z` 撤销重做（[DOC]）。
- 页面操作（增删/重排）也应纳入撤销栈（[INF]）。

## 4. 协作与同步（[DOC]）

- 多设备编辑、评论/批注、安全链接分享、团队成员编辑权限、自动保存（[DOC]）。
- 数据流中**持久化与同步是默认且持续的**（同图片编辑器）。

## 5. 数据流（[INF]）

```
上传 PDF 文件
   │
   ▼
导入拆解管线(服务端版式/OCR分析) → 生成 Canva 设计(页面+元素+批注层)
   │
   ▼
用户编辑: 改文本/图/元素 + 批注(线条/形状/签名/评论) + 页面增删重排
   │
   ▼
模型更新 → 撤销栈; 视图刷新(DOM/SVG); 防抖写云端(自动保存/同步)
   │
   ▼
导出: 按页面顺序 + 元素/批注重新合成 PDF(或 JPG/PNG/SVG/PPT)
```

### 与 Photopea 的关键差异
- **导入拆解**：Canva 把 PDF 变结构化可编辑元素；Photopea 以栅格/矢量页打开，结构化拆解弱。
- **页面模型**：Canva 多页 PDF 为一等公民；Photopea 单画布无页面。
- **协作**：Canva 云原生；Photopea 本地。
