# Canva PDF 编辑器 · UI 结构

> 维度一：面板布局、工具栏、操作流、页面跳转。基于 `[DOC]` 与 `[INF]`。

## 1. 整体结构（[DOC]/[INF]）

Canva PDF 编辑器**复用图片编辑器的外壳**（左侧面板 / 中央画布 / 顶部导航 / 右侧属性面板），但把「页面（Pages）」提升为一等公民，并强化批注能力：

```
┌──────────────────────────────────────────────────────────────┐
│ 顶部: 上传PDF | 编辑 | 分享 | 下载(PDF/JPG/PNG/SVG/PPT)        │
├─────────────┬────────────────────────────────┬───────────────┤
│ 左侧面板     │        中央画布(当前PDF页)        │ 右侧属性面板  │
│ (素材/文字/  │   页面被拆为可编辑元素 + 批注层   │ (选中元素/   │
│  上传/工具/  │                                │  批注时)     │
│  应用)      │                                │               │
├─────────────┴────────────────────────────────┴───────────────┤
│ 底部: 页面缩略图(Pages) — 增/删/旋转/重排/提取/插入           │
└──────────────────────────────────────────────────────────────┘
```

## 2. 关键 UI 差异点（相对图片编辑器，[DOC]/[INF]）

- **页面缩略图条（Pages）成为核心**：每个缩略图 = 一个 PDF 页，支持拖放重排、删除、旋转、插入、提取、拆分（[DOC]）。
- **批注工具**：绘制线条、形状、签名，以及「评论/备注」层（[DOC]）。
- **上传入口优先**：首屏强调「上传你的 PDF」（[DOC]），进入后再编辑。

## 3. 典型操作流（[DOC]）

1. **上传 PDF**（拖放或选择文件，≤100MB / ≤300 页，[DOC]）。
2. **自动拆解**：Canva 识别文字/图像/排版/字体，转为可编辑元素（[DOC]）。
3. **逐页编辑**：在左侧面板添加文本/图片/元素；直接修改被识别出的文字；调整版式（[DOC]）。
4. **批注**：用线条/形状/签名在页面上标注；用评论功能留言（[DOC]）。
5. **页面管理**：底部缩略图拖拽重排、删除/旋转/插入/提取/拆分；可合并多个 PDF（[DOC]）。
6. **分享/下载**：生成协作链接或开通成员权限；下载为 PDF/JPG/PNG，或导出 SVG/PPT（[DOC]）。

## 4. 页面跳转（[DOC]/[INF]）

- 多页通过底部 `Pages` 缩略图切换，属同一设计文档内的页面栈（[INF]）。
- 页面增删/重排实时反映到导出 PDF 的页面顺序（[INF]）。

## 5. 与 Photopea / 图片编辑器对比（预告）

| | Canva PDF 编辑器 | Canva 图片编辑器 | Photopea |
| --- | --- | --- | --- |
| 核心对象 | 多页 PDF + 可编辑元素 + 批注层 | 单/多页设计元素 | 单画布图层栈 |
| 页面模型 | 一等公民（PDF 页） | 页面为设计页 | 无页面概念 |
| 批注 | 强（签名/评论/形状） | 弱（备注） | 弱 |
| 像素精修 | 弱 | 弱 | 强 |

详见 `04-comparison.md`。
