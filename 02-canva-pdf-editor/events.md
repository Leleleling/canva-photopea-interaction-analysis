# Canva PDF 编辑器 · 事件机制

> 维度三：指针/键盘/手势、命中测试、拖拽/缩放/对齐、批注绘制。基于 `[DOC]` 与 `[INF]`（同图片编辑器，元素即 DOM/SVG）。

## 1. 与图片编辑器一致的部分（[DOC]/[INF]）

- 元素为 DOM/SVG 节点，命中测试交给浏览器；选中→属性面板→上下文工具条（见 `01-canva-image-editor/events.md`）。
- 拖拽素材、控制柄缩放/旋转、对齐参考线、快捷键（`Ctrl+D/G/Z`、`Ctrl+滚轮` 缩放）均适用（[DOC]）。

## 2. 批注交互（[DOC]）

- **绘制线条/形状/签名**：在画布上拖拽绘制，作为叠加元素（[DOC]）。签名可能支持手写轨迹捕获（指针事件记录路径，[INF]）。
- **评论/备注**：选中区域或元素后添加评论，以评论层/气泡呈现（[DOC]）。
- 批注与原文解耦：批注是叠加层，不修改被识别出的原内容（[INF]）。

## 3. 页面拖拽重排（[DOC]）

- 底部 `Pages` 缩略图支持**拖放**以重新排序；删除/旋转/插入/提取/拆分（[DOC]）。
- 拖拽时为缩略图提供放置指示（[INF]），松手更新页面顺序与导出顺序。

## 4. 缩放与平移（[DOC]/[INF]）

- `Ctrl+滚轮` 缩放画布、抓手平移、顶部缩放/网格/全屏（同图片编辑器，[DOC]）。

## 5. 键盘与手势（[DOC]/[INF]）

- 快捷键与图片编辑器一致；移动端以底部工具条 + 双指缩放替代（[DOC]）。

## 6. 与 Photopea 对比（预告）

| | Canva PDF 编辑器 | Photopea |
| --- | --- | --- |
| 批注 | 结构化叠加（线条/签名/评论） | 无专门批注 |
| 页面操作 | 拖拽重排/增删/旋转/提取 | 无多页 |
| 命中测试 | 浏览器 DOM | 自研画布 |

详见 `04-comparison.md`。
