# Photopea · UI 结构

> 维度一：面板布局、工具栏、操作流、页面跳转。全部基于本机实跑观察 `[OBS]`，证据见 `assets/`。

## 1. 总体布局（四区 + 画布）

Photopea 采用经典 **Photoshop 四区布局**，DOM 层级如下（观察自 `photopea-editor-after.html` 与 `photopea-editor-doc.json`）：

```
┌───────────────────────────────────────────────────────────┐
│ 顶栏菜单 (topbar): 文件 编辑 图像 图层 选择 滤镜 视图 窗口 更多 账户 │
├──────────┬────────────────────────────────────┬───────────┤
│ 左侧工具栏│            中央画布 (<canvas>)      │ 右侧面板   │
│ (tools,  │         主画布 1011×951 (OBS)        │ 图层/通道/ │
│  19 工具) │                                    │ 路径 历史  │
│          │                                    │ 色板      │
├──────────┴────────────────────────────────────┴───────────┤
│ 选项栏 (随工具变化): 自动选择 / 文件夹图层 / 显示变换控件 / 距离 … │
└───────────────────────────────────────────────────────────┘
```

- 顶栏菜单 `topbar` 为 DOM，含 10 个菜单（[OBS] `photopea-topbar.json`）。
- 中央**主画布是 `<canvas>`**（尺寸 1011×951，[OBS]），图像与多数浮层绘制其上。
- 左/右栏为 DOM 面板（class 含 `tools` / `panelblock` / `panelhead`）。

## 2. 顶栏菜单（[OBS]）

观察文本（中文，因本机区域）：`文件 编辑 图像 图层 选择 滤镜 视图 窗口 更多 账户`。

**文件菜单下拉项（已抓到，[OBS] `photopea-menu-文件-dropdown.json`）**：
`新建项目` · `从电脑打开` · `模板` · `安装 Photopea` · `Generate Video?`

> 其余菜单（编辑/图像/图层/选择/滤镜/视图/窗口）子项在会话中部分为**画布内绘制**或 DOM 弹层，未能稳定抓取；其条目与 Photoshop 对应菜单高度一致（[INF]，见 `04-comparison.md` 与公开资料）。菜单名本身为直接观察。

## 4. 右侧面板（[OBS] `photopea-editor-doc.json`）

观察 `panelhead` 文本：
- **图层 / 通道 / 路径**（标签页，`图层通道路径≡`）—— 主图层面板，含混合模式下拉（`正常 溶解 变暗 正片叠底…`）与 `不透明度:` / `填充:` / `锁定:` 控件。
- **历史记录 / 色板**（`历史记录色板≡`）—— 历史栈面板 + 色板。
- 文档标题栏显示 `新建项目.psd`（新建文档默认名，含 `.psd` 后缀，暗示 PSD 内核）。

## 5. 选项栏（context-sensitive，[OBS]）

位于顶栏之下、画布之上。选择不同工具时内容变化；观察项含：`自动选择` `文件夹图层` `显示变换控件` `距离`。这是 Photoshop「选项栏」的复刻——把「当前工具的参数」集中放在固定一行。

## 6. 典型操作流（[OBS] + [DOC]）

1. 落地页 → 点「Start using Photopea」→ 编辑器加载。
2. `文件 ▸ 新建项目` → 弹「新建项目」对话框（预设：打印/照片/屏幕/移动/广告，含尺寸与 2ᴺ 等比、⇆ 翻转）→ 点「创建」→ 生成空白文档与画布。
3. 选工具（如 `画笔 B`）→ 选项栏出现画笔参数 → 在画布绘制。
4. 右侧图层面板管理图层、混合模式、不透明度；历史记录面板逐步回溯。
5. `文件 ▸ 从电脑打开` 导入 PSD/图片；`文件` 导出为 PSD/PNG/JPG 等。

## 7. 页面/文档模型跳转（[OBS]）

- 无「多页文档」概念（单画布 = 单文档），与 Photoshop 一致；多页由「图层」承载而非「页面」。
- 「更多 / 账户」为 Web 应用层入口（与编辑引擎解耦），属 SaaS 外壳，非编辑内核。
