# Photopea · 事件机制

> 维度三：指针/键盘/手势、命中测试、拖拽/缩放/对齐。Photopea 的「画布交互」是其核心，以下结合观察与 Photoshop 范式推断（[INF]）。

## 1. 事件总览（[INF]）

Photopea 在 `<canvas>` 上监听原生指针事件（`pointerdown/move/up`、`wheel`、`keydown`），**自行实现命中测试与工具分发**——因为它没有 DOM 元素对应每个图形对象，所有对象都在画布像素/矢量数据里。

```
pointerdown ─┐
keydown ────┼─► 事件路由: 判断当前工具 + 命中目标(图层/选区/控制点)
wheel ──────┘        │
                     ▼
              工具处理器(每种工具一个状态机)
                     │
                     ▼
              改变文档模型 / 选区 / 视图(缩放平移)
```

- 顶栏菜单、工具栏、面板为 DOM，走浏览器原生事件；**画布内对象交互走自研命中测试**（[OBS] 画布为 `<canvas>`、UI 为 DOM，二者分离）。

## 2. 命中测试（Hit Testing，[INF]）

- 选中图层：点击画布时，按**图层堆叠顺序自顶向下**做像素/形状命中判断（考虑不透明度、锁定层不可选）。
- 选区工具（M/L/W）：在画布上拉出选区，选区以**独立选区数据结构**存储（可加减、羽化）。
- 变换控制点：选中对象后显示包围框与手柄（旋转/缩放/斜切），命中手柄进入对应拖拽模式（选项栏 `显示变换控件` 即此开关，[OBS]）。

## 3. 工具状态机（[INF]）

每种工具有独立交互状态机，例如：
- **画笔 B**：`pointerdown` 记录笔迹起点 → `pointermove` 按笔压/流量累积描边 → `pointerup` 提交为一笔（压入历史）。
- **移动 V**：`pointerdown` 命中图层 → 拖拽改位置 → 松手提交（吸附/对齐在此阶段判定）。
- **文字 T**：点击画布创建文字层 → 进入文本编辑（可能复用 DOM `<textarea>` 覆盖定位，[INF]）。
- **缩放 Z / 抓手 H**：改为视图操作（缩放/平移画布），不改文档模型。

## 4. 键盘快捷键（[OBS]，见 `ui-structure.md` 工具表）

工具切换用单键（V/M/L/W/C/I/J/B/S/E/G/O/T/P/A/U/H/Z），与 Photoshop **完全一致**（[OBS] 工具 tip 文本含快捷键）。此外常见组合（[INF] 等价 Photoshop）：`Ctrl+Z` 撤销、`Ctrl+T` 自由变换、`Ctrl+J` 复制图层、`Space+拖拽` 临时抓手等。

## 5. 拖拽 / 缩放 / 对齐（[INF]）

- **拖拽**：移动工具或对象手柄拖拽时实时更新；松手前为「预览」，松手「提交」。
- **缩放视图**：滚轮/`Ctrl+滚轮` 或 缩放工具 Z；画布坐标系与视图变换矩阵分离（文档坐标 ≠ 屏幕坐标）。
- **对齐/吸附**：移动工具选项栏 `显示变换控件` 与参考线/智能参考线（[INF]，Photoshop 同款）；`自动选择` `文件夹图层` 控制点击时是否穿透组/自动选中最上层（[OBS] 选项栏项）。

## 6. 手势（[INF]）

- 触控板/触屏：双指平移/缩放（映射到 `wheel`/视图变换），取决于设备；核心仍是「视图变换矩阵」驱动。

## 7. 与 Canva 的事件机制对比（预告）

Photopea 的画布交互是 **「自研命中测试 + 工具状态机」**（因为画布无 DOM 对象）；
Canva 的画布交互更偏向 **「DOM/SVG 元素 + 框架事件绑定」**（元素即对象，命中测试交给浏览器），二者在「对象如何被选中/操作」上有范式级差异。详见 `04-comparison.md` 与 `01-canva-image-editor/events.md`。
